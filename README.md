# Whoa Unit Frames

Whoa Unit Frames enhances the default Blizzard unit frames while keeping the familiar Classic look — still very close to the original UI, with class colors and a few style choices. Whoa, Thick, and Classic used to be separate addons; they're all here now.

Supported clients: Classic Era · Burning Crusade Classic (Anniversary) · Mists of Pandaria Classic · Retail

## Styles

Whoa Frames — Classic Blizzard look with Whoa bar geometry
Thick Frames — the same familiar frames with thicker health / power bars
Classic Frames — default Blizzard proportions
Alpha Frame — WotLK Death Knight sword chrome with runic fill (Rage fill for Forever warriors)
BlizzCon '07 Frame — BlizzCon player border (Death Knight / Forever warrior)
Druid Frame — stacked cat/bear chrome with alternate mana bar (default / elite / rare elite)
Light or dark frame art on Whoa, Thick, and Classic.

## Features

Class-colored health bars (player / party / NPCs configurable)
Status bar textures, fonts, and number abbreviation styles
Buff / debuff icon size
Combat feedback colors and numeric threat display
Portrait modes, frame scale, player name visibility, name background
Player border rarity (default / elite / rare elite)
Class power bars by client (combo points, runes, holy power, shards, totems, etc.)
Some features are limited by Blizzard client restrictions and may differ by game version.
